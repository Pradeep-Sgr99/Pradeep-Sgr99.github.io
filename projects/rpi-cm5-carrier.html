RPI CM5 Carrier Board

Raspberry Pi Compute Module 5 carrier — camera, USB 2.0, environmental sensing and a hardware laser interlock
Role: Hardware design & PCB layout Product: LightScope (lighthearted) Compute: Raspberry Pi Compute Module 5 Interface: 2× 100-pin CM5 connectors

Overview

This board carries a Raspberry Pi Compute Module 5 and breaks out the interfaces the LightScope needs: a camera module input, USB 2.0, four RGB status LEDs and an SHT31A temperature / humidity sensor. Its defining feature is an independent hardware laser interlock — the laser's 5 V supply passes through a P-FET high-side switch that only a hardware 555 timer line can hold on, so software cannot power the laser on its own.

Feature breakdown

Function Implementation
Compute module interface Two 100-pin high-density board-to-board connectors (RPI_CN1, RPI_CN2) carry the full CM5 interface — power, USB, PCIe, camera (CSI), display (DSI), GPIO, I²C and UART. The carrier supplies the module rails and handles power-button / RTC lines.
Camera module MIPI CSI-2 camera routed from the CM5 connectors to the camera connector, differential pairs length-matched and referenced to a solid ground plane.
Laser control & safety The laser supply LASER_VCC_+5VDC is gated by a DMG2305UX-7 P-channel high-side switch, whose gate is driven by a DMG2302UKQ-7 N-channel level-shifter from the 555_OUT line — so a hardware 555 timer, not software, holds the laser powered. If 555_OUT is absent or times out, the P-FET gate returns to its source pull-up and the laser drops unpowered (fail-safe OFF). A second identical N-FET / P-FET pair sets the CL1 / CL2 channel from an isolated CM5 line (LASER_CL1_CL2_SET_ISO) — default CL1, driven high selects CL2. Each path has its own yellow status LED; the laser head connects on a shielded 3-pin JST (SM03B-SR8S) with a TVS/ESD array.
Status indication Four RGB LEDs for system state — power / ready / active / fault (including a distinct “laser armed” indication). Discrete (non-addressable) RGB parts, each colour switched low-side by a DMG2302UKQ-7 N-channel MOSFET from CM5 GPIO.
Environmental sensing SHT31A-DIS-B10KS temperature + humidity sensor on I²C (±0.2 °C / ±2 %RH) for enclosure climate and condensation / thermal guarding.
USB 2.0 USB 2.0 host from the CM5 to a USB-A connector with a switched, current-limited VBUS (VBUS_EN) and ESD protection on the data pair.

Laser control circuit

Two channels use the same two-transistor topology — a logic-level DMG2302UKQ-7 N-FET translates the control signal and pulls the gate of a DMG2305UX-7 P-FET high-side switch:

Path Control in Switches Default state
Laser power 555_OUT (hardware timer) Q7 (N) → Q5 (P) → LASER_VCC_+5VDC Off — no 555_OUT ⇒ P-FET off, laser unpowered
Channel select LASER_CL1_CL2_SET_ISO (isolated, from CM5) Q3 (N) → Q1 (P) → LASER_CL1_CL2_SEL CL1 (line low / undriven); +5 V selects CL2
The laser cannot be powered by software alone. Its 5 V supply passes through the P-FET switch that only the hardware 555 line can hold on, so a frozen process, kernel panic, unplugged cable or brown-out all leave the laser in its off state with no CPU involvement. The channel-select line is galvanically isolated from the CM5 and defaults to CL1.

Connectors & I/O

  • CM5: 2× 100-pin connectors (RPI_CN1 / RPI_CN2) to the compute module.
  • Camera: MIPI CSI-2 camera connector.
  • Laser head: shielded 3-pin JST (SM03B-SR8S) — switched 5 V, CL1/CL2 select, GND, with a TVS array.
  • USB: USB 2.0 type-A host port.
  • Peripheral headers: JST connectors for fan, GPIO, power and system peripherals; RTC backup battery.
  • Designed to stack with the LH power supply board (2S2P charger) for portable operation.

Layout notes

  • CM5 connectors placed to the module's mechanical drawing, with body and heatsink keep-outs.
  • MIPI camera lanes length-matched and impedance-controlled, kept clear of the switching and LED drive nets.
  • The 555 timer and the laser P-FET / N-FET switch grouped together near the laser connector, wired fail-safe so loss of 555_OUT de-asserts the high-side switch; laser lines kept short with the TVS array right at the connector.
  • Channel-select line kept in its isolated domain up to the transistor pair; per-path status LEDs by the connector for a direct visual check.
  • SHT31A placed away from local heat sources (regulators, CM5) so its reading tracks the enclosure, not the board.
