HOW TO ADD YOUR BOARD IMAGES TO THE PORTFOLIO
=============================================

Save each board picture into THIS folder (Photo/boards/) using the exact
file name below. Use .png (or change the name in PortPolio.html to .jpg).

!! WATCH THE EXTENSION !!
Windows can save the file as "navix9-top.png.png" (double .png) when
"Hide extensions for known file types" is on and you type ".png" yourself.
The page looks for "navix9-top.png" exactly - a doubled extension = broken
image. In the Save dialog either leave the name WITHOUT ".png" (the PNG
type adds it once), or turn on View > File name extensions and check the
final name.

Until a file exists, its card shows a dashed "Add image" placeholder, so you
can drop them in one by one and refresh the page.

To add MORE boards later: copy one <figure class="board-card"> ... </figure>
block in PortPolio.html (inside <div class="board-gallery">), change the
src / href file name and the <figcaption> text.

To remove a card you don't want: delete its <figure> ... </figure> block.
